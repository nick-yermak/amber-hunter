# ADR-004: Baltic Explorer UI primitives

**Status:** Proposed record of approved baseline choice — confirm before marking Accepted.  
**Date:** 2026-11-11

## Decision
Tailwind CSS, Angular CDK, Lucide; small internal component set; light MVP and references for home/map.

## Context / tradeoff
Adopt the smallest maintainable architecture serving Amber Hunter MVP and portfolio goals. Verify versions, pricing, security and API limits during bootstrap. Further implementation details remain open.

## Consequences
Document any divergence and create a follow-up ADR rather than silently changing this baseline.

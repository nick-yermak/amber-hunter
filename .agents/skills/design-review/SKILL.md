# Design Review
Read approved design system and relevant reference image. Review real screenshots and UI diff, not author's claims. Verify layout hierarchy, semantic tokens, type, touch size, keyboard focus, color contrast, loading/stale/error/unsafe/unknown states, PL/EN/RU wrapping, mobile/tablet/desktop. Treat AI-generated numbers/map boundaries as non-factual illustrative content; never demand pixel-perfect matching. Note specific reproduction steps, severities and file/element references. Reviewer never edits implementation.
